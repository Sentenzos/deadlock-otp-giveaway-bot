# Twitch → Telegram Giveaway Bot

Бот проводит розыгрыши для одного Telegram-канала или одной Telegram-группы. Участник допускается, если:

1. привязал свой Telegram к Twitch;
2. находился в чате Twitch в течение заданного времени во время активного розыгрыша;
3. отправил минимум заданное число сообщений в Twitch-чате с учётом заданного интервала между засчитанными сообщениями;
4. остаётся подписчиком канала или участником группы на момент выбора.

Время означает присутствие в **чате** Twitch. Это не измерение фактического просмотра видеоплеера. Минуты и сообщения засчитываются только когда Twitch API показывает, что стрим live.

## Установка

Нужен Python 3.11+.

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Заполните `.env`, затем добавьте Telegram-бота в нужный канал или группу и сделайте его администратором. Администраторский статус нужен, чтобы `getChatMember` мог надёжно проверить подписку/членство кандидатов и чтобы бот мог публиковать сообщения розыгрыша.

Для чтения чата Twitch и проверки live-статуса укажите User OAuth-токен Twitch-аккаунта со scope `chat:read`. Для отправки периодических анонсов в Twitch-чат нужен также scope `chat:edit`. Для админской команды `/viewers` дополнительно нужен scope `moderator:read:chatters`; аккаунт токена должен быть владельцем канала или его модератором. Если в существующем токене нет `chat:edit`, создайте новый токен с нужными правами и замените `TWITCH_OAUTH_TOKEN` в `.env`. Бот подключается к `#deadlock_otp` по защищённому WebSocket IRC и проверяет live-статус через Twitch Helix API. По умолчанию автоматическая проверка выполняется каждые 10 секунд; команда `/status` дополнительно запрашивает актуальное состояние сразу.

Запуск:

```powershell
py -m app
```

На Windows можно запускать без ручного ввода команд: дважды кликните `start_bot.cmd` в папке проекта.  
Если нужен ярлык на рабочем столе, запустите PowerShell в папке проекта и выполните:

```powershell
.\create_desktop_shortcut.ps1
```

## Привязка участника

1. Пользователь открывает бота по ссылке из анонса или пишет ему в личные сообщения `/link`.
2. Бот выдаёт одноразовый код на 10 минут.
3. Пользователь отправляет в Twitch-чат: `!link КОД`.
4. Бот подтверждает связь аккаунтов и регистрирует пользователя в текущем розыгрыше.

Код доказывает, что один и тот же человек контролирует оба аккаунта; сайт и OAuth участников не нужны. `/link` необходимо выполнять заново в каждом новом розыгрыше — постоянная связь Telegram и Twitch сама по себе не считается заявкой на участие. Код привязан к конкретному розыгрышу, поэтому старый код нельзя применить в следующем. Повторный `/link` в течение 10 минут возвращает тот же действующий код, а не отменяет предыдущий. Если сборщик ещё не вошёл в Twitch-чат или переподключается, бот не выдаёт код и просит повторить `/link` через несколько секунд — так команда `!link` не потеряется, пока Twitch-соединение недоступно.

## Команды участника

Команды участника работают в личных сообщениях с ботом.

```text
/link      # зарегистрироваться в текущем розыгрыше через одноразовый код
/status    # узнать статус учёта и увидеть свои минуты, сообщения и выполнение условий
```

Чтобы один пользователь не мог заспамить бота в личных сообщениях, на обычные команды действует короткий cooldown: `/status` — 5 секунд, `/link` и ссылка из анонса `/start link` — 10 секунд, обычный `/start` — 3 секунды. Команды владельца не ограничиваются.

Если `/status` не отвечает вообще, значит недоступна Telegram-часть бота. При каждом `/status` бот пытается немедленно обновить online/offline через Twitch API; если Twitch временно не отвечает, используется последний известный статус. Если Twitch-сборщик переподключается, команда покажет предупреждение, что новые минуты и сообщения могут не записаться. При запуске и после разрыва соединения старый список присутствующих очищается и заново собирается из Twitch-чата, поэтому время простоя сервиса не начисляется. Незарегистрированному пользователю `/status` предложит пройти `/link` для активного розыгрыша. Все пользователи также видят в `/status`, сколько человек уже зарегистрировано в текущем розыгрыше.

При переходе Twitch-стрима в live бот публикует в Telegram-канале/чате оформленный анонс с названием и ссылкой на канал. Повторный анонс того же стрима не публикуется, в том числе после перезапуска бота. Если новый стрим начался менее чем через 30 минут после offline, анонс пропускается. Время offline и ID последнего анонса хранятся в SQLite.

## Команды владельца

Команды работают только для `OWNER_TELEGRAM_ID`. Если `TELEGRAM_REQUIRED_CHAT_ID` указывает на канал, пишите команды владельца в личные сообщения боту: старт и результаты бот опубликует в канал сам. Если это группа, команды можно писать и в группе.

```text
/viewers                                  # показать владельцу подключённых участников Twitch-чата
/twitch_announce on 15                    # включить анонсы розыгрыша в Twitch каждые 15 минут
/twitch_announce off                      # выключить Twitch-анонсы
/twitch_announce status                   # показать состояние и расписание Twitch-анонсов
/giveaway start <МИНУТЫ> <СООБЩЕНИЯ> [ПОБЕДИТЕЛИ] [ИНТЕРВАЛ_СЕК] [МИН_УЧАСТНИКОВ] [--end ДД.ММ.ГГГГ ЧЧ:ММ] [НАЗВАНИЕ | НАГРАДА]
/giveaway start 60 5 3 30 10 --end 31.12.2030 22:30 Розыгрыш ключей | Steam key
/giveaway announce_start                   # отдельно анонсировать старт в канал/чат
/giveaway status                           # показать текущую статистику владельцу
/giveaway participants                     # показать участников активного или последнего завершённого розыгрыша
/giveaway participants Розыгрыш ключей     # показать участников конкретного розыгрыша по названию
/giveaway finish                           # запросить завершение и получить подтверждение
/giveaway finish confirm                   # подтвердить завершение в течение двух минут
/giveaway finish force                     # запросить завершение с игнорированием минимума участников
/giveaway finish force confirm             # принудительно завершить и выбрать победителей
/giveaway finish cancel                    # отменить ожидающее подтверждение
/giveaway announce_finish                  # отдельно анонсировать завершение и победителей в канал/чат
/giveaway reroll                           # выбрать ещё одного победителя из того же списка
```

Время и сообщения считаются после `/giveaway start`, но только когда стрим live. Зарегистрироваться через `/link` и `!link КОД` можно заранее, пока стрим ещё offline; повторная `/link` после успешной регистрации сообщит, какой Twitch-аккаунт уже привязан. Статистика Twitch-чата собирается с начала розыгрыша и сохраняется по Twitch-нику ещё до `/link`; после регистрации уже накопленные показатели становятся видны участнику. Само сообщение `!link КОД` подтверждает присутствие и запускает учёт времени только во время live, но не засчитывается как обычный комментарий. Если задан `ИНТЕРВАЛ_СЕК`, слишком быстрые сообщения намеренно не увеличивают счётчик. Кандидатом становится только пользователь, который выполнил `/link` именно для этого розыгрыша. Команда `/giveaway start` только создаёт розыгрыш; публичный старт со ссылкой на личный чат бота публикуется отдельной командой `/giveaway announce_start`. Первый `/giveaway finish` ничего не закрывает, а создаёт подтверждение на две минуты. Обычное завершение выполняется через `/giveaway finish confirm`; если допущенных кандидатов меньше параметра `МИН_УЧАСТНИКОВ`, оно завершит розыгрыш без победителей. Команда `/giveaway finish force confirm` игнорирует только этот минимум и выбирает победителей из имеющихся допущенных кандидатов. Требования по времени, сообщениям, регистрации и членству в Telegram при этом сохраняются; если подходящих кандидатов нет совсем, выбрать победителя невозможно. `/giveaway finish cancel` отменяет ожидающее подтверждение. Бот сразу пишет каждому выбранному победителю в личный чат. Личное сообщение содержит название розыгрыша, награду и привязанный Twitch-логин. Новый победитель, выбранный командой `/giveaway reroll`, тоже получает это уведомление. Если боту не удалось доставить сообщение, розыгрыш всё равно завершается, а владелец получает предупреждение. `/giveaway announce_finish` всегда публикует итог: Telegram-ник и Twitch-логин каждого победителя либо сообщение о завершении без победителей. Если минимум был принудительно проигнорирован, это отмечается в итоговом анонсе. Если у победителя нет публичного Telegram-ника, используется его кликабельное отображаемое имя. Автор Twitch-канала и владелец Telegram-канала участвуют по умолчанию. Команда `/giveaway participants` показывает только зарегистрировавшихся в выбранном розыгрыше и их минуты и сообщения. Если после команды указать название, бот найдёт самый свежий розыгрыш с таким названием без учёта регистра. При завершении бот проверяет каждого кандидата через Telegram API и исключает тех, кто не подписан на нужный канал или не состоит в нужной группе.

Периодические Twitch-анонсы для каждого нового розыгрыша по умолчанию выключены. `/twitch_announce on 15` включает их с интервалом 15 минут; допустим интервал от 1 до 1440 минут. Первый анонс отправляется при ближайшей возможности, последующие — по заданному расписанию. Когда стрим offline, Twitch-чат переподключается или Twitch API временно не может подтвердить актуальный live-статус, расписание ставится на паузу; после восстановления отправляется один актуальный анонс, без накопившейся серии сообщений. Повторная команда включения не сбрасывает уже начатый интервал. Настройка и время последней успешной отправки сохраняются в SQLite и переживают перезапуск. Новый розыгрыш не наследует настройку предыдущего. Автоматические объявления не засчитываются как комментарии участника.

Исключения задаются независимо в `.env`:

```dotenv
TWITCH_EXCLUDED_LOGINS=nightbot,streamelements
TELEGRAM_EXCLUDED_USERNAMES=blocked_user,another_user
```

Значения перечисляются через запятую; `@` перед Telegram-ником необязателен, регистр не учитывается. Чтобы никого не исключать, оставьте оба значения пустыми. Telegram-исключение работает по публичному `@username`; пользователя без username можно исключить по его Twitch-логину.

Награда отделяется от названия символом `|`. Если `|` не указан, розыгрыш создаётся без отдельного текста награды.

Параметр `--end` необязателен. Дата и время указываются по Москве в формате `ДД.ММ.ГГГГ ЧЧ:ММ`. Это публичный плановый дедлайн: бот показывает его в анонсе и статусе, но не завершает розыгрыш автоматически. Для выбора победителей по-прежнему нужно выполнить `/giveaway finish`, затем `/giveaway finish confirm`.

Для удобства Telegram command menu также регистрирует алиасы:

```text
/giveaway_create
/giveaway_announce_start
/giveaway_status
/giveaway_participants
/giveaway_finish
/giveaway_announce_finish
/giveaway_reroll
/twitch_announce
```

## Тесты

Полный набор проверок запускается командой:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты проверяют публичные и административные команды, права владельца, привязку к конкретному розыгрышу, повторное и одновременное получение одного действующего кода, запрет выдачи кода при отключённом Twitch-сборщике, сохранение статистики до `/link`, восстановление сессии после обрыва, неблокирующую отправку Telegram-подтверждения, личную статистику, число зарегистрированных участников, online/offline-переходы Twitch, анонс запуска стрима и 30-минутное окно подавления, периодические Twitch-анонсы и их права OAuth, паузу offline, сохранение расписания и защиту от учёта собственных объявлений, учёт только во время live, админский список Twitch-чата, интервал сообщений, выбор только подходящих кандидатов, личные уведомления победителям, членство в Telegram, минимальное число участников, завершение без победителей, анонсы розыгрышей и перевыбор без повторов.

## Ограничения и эксплуатация

- Процесс должен работать весь период розыгрыша. Для постоянной работы используйте VPS, Docker или сервис Windows.
- После перезапуска бот продолжит открытый розыгрыш. Присутствие, которое пришлось на момент недоступности сервиса, не может быть восстановлено.
- Не публикуйте `.env` и OAuth-токены. Перед запуском проверьте правила платформы и условия конкретного розыгрыша.
